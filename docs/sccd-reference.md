# The SCCD Reference

Standard Classification of Comparison Dimensions, version 4.2.

The Standard Classification of Comparison Dimensions (SCCD) organizes the dimensions on which standing is compared into sectors and industries. This reference lists the 480 dimensions in the classification at the outset, in 12 sectors and 63 industries. Further dimensions are classified from time to time; see Dimension Discovery in the [Methodology](methodology.md#11-dimension-discovery).

Identifiers are permanent. A dimension's identifier is never reissued, and the three-letter prefix identifies its sector.
